# Chameleon

**Los sitios web están hechos para el promedio. Chameleon los adapta para que cualquiera logre lo que vino a hacer.**

Dar de baja un servicio, pedir un certificado, encontrar el horario de una sucursal: tareas simples que en muchos
sitios se vuelven un laberinto. El dueño del sitio rara vez lo arregla, y quien lo sufre no puede hacer nada.

## Qué hace

Chameleon es una extensión de navegador que cambia el diseño de un sitio sin tocar el original: aplica un **tema**
encima de la página. El tema puede ajustar el estilo o reorganizar una sección completa, y siempre puedes volver a la
página original.

## Cómo decide qué cambiar

Antes de tocar un sitio, agentes de IA lo estudian:

- un **Catalogador** descubre qué viene a hacer la gente en él;
- una **Guía** encuentra y verifica el camino para lograrlo;
- un **Visitante**, un usuario sintético que solo ve la pantalla, lo intenta como lo haría una persona;
- un **Diseñador** escribe el tema con la evidencia de dónde se perdió.

Todo corre en paralelo en la nube, y se puede ver a los agentes trabajar mientras recorren el sitio.

## Multiplayer

Lo que se aprende de un sitio sirve para todos. Cuando alguien visita una página que todavía no tiene tema, los
agentes la estudian y el resultado queda disponible para cada persona que usa Chameleon. Cada visita mejora el sitio
para la siguiente.
